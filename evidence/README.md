# evidence : preuves

Un fichier par preuve : evidence/<id>.md (modèle : TEMPLATE.md). PROGRESS.md y renvoie.
- TESTS AUTO OK : URL du run CI vert (dans la colonne Preuve) ou fichier ici avec le log utile.
- VÉRIFIÉ SIMULATEUR : fichier ici (scénario, GPX utilisé, sortie).
- VÉRIFIÉ SUR APPAREIL : fichier ici avec mesures réelles ET la ligne `Confirmé par l'utilisateur : <date, citation>`. Seul l'utilisateur confirme.
Pas de capture ou de log inventé.
